PLATTEGROND WEBSITE

Publiceren via GitHub Pages:
1. Maak een gratis account op https://github.com
2. Maak een nieuwe openbare repository, bijvoorbeeld 'plattegrond'.
3. Upload index.html in de hoofdmap van de repository.
4. Ga naar Settings > Pages > Build and deployment.
5. Kies Deploy from a branch, branch 'main', folder '/ (root)' en Save.
6. Open de gepubliceerde link: https://GEBRUIKERSNAAM.github.io/plattegrond/

Let op: een openbare GitHub Pages-website is voor iedereen met de link bereikbaar. Sla geen vertrouwelijke klantgegevens in de broncode op.
De adreszoekfunctie en kadastrale kaart hebben internet nodig.
